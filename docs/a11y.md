# Accessibilité et qualité : résultats des vérifications

Toutes les mesures portent sur le site HTML, servi localement (`npm run dev`), au 2 novembre 2026. Elles sont rejouables.

| Contrôle | Commande | Résultat |
|---|---|---|
| axe-core (WCAG 2 A, AA, 2.1, 2.2, bonnes pratiques), clair et sombre, 1440 et 390 px | `npm run axe -- <route>` | zéro violation sur les 9 routes |
| Lighthouse (performance, accessibilité, bonnes pratiques) | voir ci-dessous | 100 / 100 / 100 sur 5 écrans, LCP 1,1 s, CLS ≤ 0,002 |
| Chaque écran tient dans la fenêtre sans défilement de page (≥ 1024 px) | `npm run fit` | 14 sur 14 à 1440 × 900 et 1280 × 720 |
| Parcours de bout en bout | `npm run verif` | toutes les vérifications passent |
| Jetons : contraste AA clair et sombre | `npm run tokens:check` | validés |

## Ce que `npm run verif` joue réellement

Upload réel d'un fichier, puis vérification ; les quatre erreurs injectables (réseau avec « Réessayer », fichier trop lourd, assistant IA indisponible, plus la session expirée et la connexion perdue avec reprise automatique) ; retirer, annuler le retrait, annuler un envoi en cours, remplacer ; format refusé ; invitation de l'experte-comptable, dépôt de son côté visible chez Fabienne, absence de tout montant sur sa vue ; visite guidée en 7 étapes ; écran de bienvenue et changement de profil ; règles des messages de relance ; mobile 390 px sans défilement horizontal sur 9 routes ; mode sombre ; navigation clavier (lien d'évitement, Tab sans piège, contour de focus, Entrée qui valide).

## Lighthouse

Exécuté avec le Chrome de Playwright : `npx lighthouse http://127.0.0.1:5180/<route> --only-categories=performance,accessibility,best-practices --chrome-flags="--headless=new --no-sandbox"`. Scores 100 / 100 / 100 sur `/`, `/bonjour`, `/eligibilite`, `/demande/pieces`, `/pro/dossiers/argile`.

## Pratiques retenues

Lien d'évitement, titre de page par route, `lang="fr"`, focus placé sur le titre à chaque changement de page ou de question, `aria-live` pour les statuts de dépôt, `<dialog>` natifs (piège de focus et Échap fournis par le navigateur), statuts toujours en icône et texte, cibles de 44 px, `prefers-reduced-motion` respecté.

## Limites connues

Non testé avec un lecteur d'écran réel (VoiceOver, NVDA) : seuls des contrôles automatiques et un parcours clavier ont été joués. Pas de test sur appareil mobile physique, seulement une fenêtre de 390 px. Les durées de parcours ne sont pas chronométrées avec de vraies personnes.
